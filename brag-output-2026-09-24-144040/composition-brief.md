# Hyperframes Composition Brief: ProjectsByAxy (Cinematic — Full Site Tour)

## Objective
A trailer-scale 25s tour of every real section of ProjectsByAxy, anchored by the site's own mission-statement copy.

## Output
- Composition directory: `brag-output-2026-09-24-144040/composition/`
- Rendered video: `brag-output-2026-09-24-144040/brag.mp4`
- Format: landscape — 1920x1080, Duration: 25s

## Source Material
Verbatim from the real site: "We don't build websites. We engineer digital ecosystems that shift market realities." / "PROJECTSBYAXY // AI SOLUTIONS" / "Shift your reality." / 6 service names / "Hyderabad. India-Built. World-Deployed." + stats (25+/20+/98%) / process phases (Scan, Architect, Deploy, Sync) / 3 project titles / 3 pricing tier names / one testimonial quote / the real Intake Terminal card + "TRANSMIT REQUEST →" + "REQUEST TRANSMITTED"

## Creative Direction
- Tone preset: cinematic, adapted for full-coverage pacing (see `brag-plan.md` "Interpretation" — ~2-3.5s per beat instead of the tone's usual 3-5s, to fit all 8 real sections inside the 25s ceiling)
- Full-bleed, single-focus per beat. ALL CAPS / heavy Archivo Black. Dramatic wipes/crossfades. No per-section SFX chatter — sparse hits only at the two biggest reveals and the terminal interaction.

## Visual Identity
Background `#000000`, text `#ffffff`/reduced-opacity white, accent `#fb923c`. Display: Archivo Black. Body/label: JetBrains Mono.

## Storyboard
See `brag-plan.md` — 10 scenes: Hook (mission statement, 3s) → Wordmark (2.5s) → Services (2.5s) → About (2.5s) → Process (2.5s) → Projects (2.5s) → Pricing (2s) → Testimonials (2s) → Intake Terminal (3.5s) → Outro (2s).

## Hyperframes Instructions
Load `hyperframes-core`, `hyperframes-animation`, `hyperframes-cli`. Run `npx hyperframes check` before render.
